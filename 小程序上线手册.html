微信小程序上线手册

从注册到发布共 8 步 · 前 6 步当天约 40 分钟 · 审核另需 1–3 个工作日
✓
代码这边已经准备好了
下面这些你都不需要做，只是让你心里有数
  • 项目在 小程序版/ 目录，共 10 个文件，直接可导入
  • 无需登录、无网络请求、不收集任何用户信息 —— 这点在审核时是加分项
  • 所有数据用 wx.setStorageSync 保存在手机本地，不上传服务器
  • 没有使用 web-view（个人主体小程序本来就禁用这个组件，已规避）
  • 计划数据与网页版完全一致：9 周任务 + 9 组工具盘点表
  • appid 现在填的是 touristappid（占位），导入时开发者工具会让你换成自己的
一句话：代码是成品，你只需要走一遍「注册 → 导入 → 提交审核」的行政流程。
1
注册小程序账号
约 10 分钟 · 需要：一个全新邮箱 + 身份证 + 本人微信
  1. 电脑浏览器打开 mp.weixin.qq.com，点右上角「立即注册」，选择「小程序」
  2. 填邮箱 —— 必须是从来没注册过微信公众平台的邮箱。最省事的办法是现注册一个 QQ 邮箱
  3. 去邮箱点激活链接，回到注册页继续
  4. 主体类型选「个人」
  5. 填身份证姓名 + 号码，用本人微信扫码做身份验证
  6. 填手机号收验证码
  7. 设置小程序名称（见下方注意事项），完成后就进后台了
不花钱。个人主体小程序做不了微信认证，所以也不存在那 300 元认证费。个人主体是完全免费的。
名称要慎重：个人主体的名称一年只能改 2 次，而且不能和已有小程序重名。「主题打卡工作台」很可能已被占用，先想好 2–3 个备选，例如：小小打卡手册 / 日常三件事 / 今日三格 / 三月计划本。
2
拿到 AppID
约 2 分钟
  1. 登录 mp.weixin.qq.com（用刚注册的邮箱）
  2. 左侧菜单 →「开发管理」→「开发设置」
  3. 在「开发者 ID」里找到 AppID(小程序ID)，形如 wx 开头的一串字符
  4. 复制它，第 4 步要用
同页还有一个 AppSecret。这个工具完全不需要 AppSecret，不要复制、不要发给任何人（包括我）。
3
安装微信开发者工具
约 10 分钟（下载看网速）
  1. 打开 developers.weixin.qq.com/miniprogram/dev/devtools/download.html
  2. 选「稳定版 Stable Build」→ Windows 64 下载安装
  3. 首次打开需要微信扫码登录 —— 用注册账号时那个微信
这是官方 IDE，装完大概 1GB 左右。如果你电脑是 Mac，选 macOS 版本即可。
4
导入项目
约 3 分钟 · 这一步最容易出错，仔细看
  1. 点左上角「+」新建项目（选「导入项目」也行）
  2. 目录：选择 小程序版 这个文件夹
    注意是选到「小程序版」这一层，不要再往里点进 pages
  3. AppID：粘贴第 2 步复制的那串
  4. 后端服务：选「不使用云服务」
  5. 点「确定」，等它编译几秒
怎么判断导入成功：左侧文件树能看到 pages/index，中间模拟器出现米白底色 + 金色边框的界面，顶部有「早睡 · 备考 · 全屋整理」标题。看到这个就成了。
选错目录会报「app.json 未找到」—— 这不是代码问题，重新导入、目录选到 小程序版 即可。
5
真机预览，确认在手机上正常
约 5 分钟
  1. 点工具上方的「预览」按钮
  2. 用手机微信扫出现的二维码
  3. 在手机上都点一遍：今日打卡 / 全览日历 / 睡眠记录 / 方案说明 / 工具清单
  4. 重点测这个：勾几个任务打勾 → 完全退出小程序 → 再打开 → 看勾还留着吗
预览版二维码只有你自己的微信能扫开，别人扫是无效的，不用担心被人看到。这一步是提审前最后一次自检，务必走完。
6
上传代码
约 3 分钟
  1. 点开发者工具右上角的「上传」
  2. 版本号填 1.0.0
  3. 项目备注填「首个版本」
  4. 确定，等进度条走完
上传成功后，去 mp 后台「管理 → 版本管理」，能在「开发版本」里看到这个 1.0.0。
7
提交审核
约 10 分钟 · 整个流程里最容易被驳回的一步
  1. mp 后台 → 左侧「管理」→「版本管理」→ 开发版本 →「提交审核」
  2. 功能页面：选择 pages/index/index
  3. 服务类目：选「工具 → 效率」；如果这个子类目不可选，就选「工具 → 其他」
  4. 标签：填「打卡」「日程」「计划」这类中性词
  5. 测试账号：留空。不要编造账号密码
  6. 审核备注：照抄下面这段
审核备注（直接复制）：
本小程序为个人日程与习惯打卡工具，无需登录即可使用，打开即为功能首页。所有用户填写的数据均通过 wx.setStorageSync 保存在用户手机本地，不上传任何服务器，不收集任何个人信息，无网络请求，无社交与支付功能。
两个必避的坑：
① 绝对不要选「健康管理」「医疗」「教育」类目 —— 这些需要资质，个人主体选了必被驳回。
② 简介和备注里不要出现「考试」「备考」「复习」 这类词，容易被判到教育类目。就用「日程」「习惯」「计划」来表述。
8
发布
1 分钟 · 前提是审核已通过
  1. 审核通过后，mp 后台「版本管理」里会出现「审核版本」
  2. 点「发布」
  3. 之后在微信里搜小程序名称，或从「发现 → 小程序 → 最近使用」都能打开
发布后它就是永久稳定的了，不再依赖任何沙箱或临时链接。

常见驳回原因与改法

驳回理由真实原因怎么改
服务类目与内容不符类目选错了，或选到了需要资质的类目改成「工具 → 效率」或「工具 → 其他」，重新提交
小程序简介含违规内容简介里提到了考试 / 教育相关表述改成中性的工具描述，如「个人日程与习惯打卡工具」
未配置用户隐私保护指引微信强制要求，从 2023 年起所有小程序都要填后台「设置 → 服务内容声明 → 用户隐私保护指引」，声明不收集任何信息，提交后即可
名称与已有小程序重复重名换备选名称。个人主体一年只有 2 次改名机会，第一次就选好
功能无法正常体验审核员打开后不知道干什么，或以为要登录在审核备注里写清「无需登录，打开即用，所有数据保存在本机」（上面那段可直接用）
涉及健康 / 医疗内容「早睡」「作息」被理解成健康管理把相关表述改成「作息打卡」「日常计划」，类目保持在工具类
被驳回不用慌，绝大多数是类目或简介的表述问题，改完重新提交就行，不影响你继续用网页版。

开发者工具常见报错

现象原因解决
报错「app.json 未找到」导入时目录选深了一层或选到了父目录重新导入，目录精确选到 小程序版
报错找不到 pages/index/index文件被误删或没完整复制检查 小程序版/pages/index/ 下是否有 4 个文件：index.js / index.json / index.wxml / index.wxss
模拟器一片空白调试基础库版本过低右上角「详情 → 本地设置」，把调试基础库调到 3.0 以上
提示 wx.getStorageSync 相关警告正常的 API 调用提示不用管，不影响功能
界面样式不对 / 颜色丢失基础库过旧，不支持 CSS 变量同样是把调试基础库调到 3.0 以上

时间怎么安排

第 1–6 步：当天约 40 分钟 第 7 步审核：1–3 个工作日 被驳回重提：再加 1–3 天
  • 建议在 9 月内把 1–7 步走完。留出被驳回重提的缓冲，别等到 11 月考试前才折腾
  • 审核提交后你什么都不用做，等通知就行。这段时间网页版照常用
  • 如果 11 月前还没发布成功，直接用网页版或把 HTML 存到手机上，不影响三个目标的执行
工具永远只是工具。早睡、备考、整理这三件事本身的节奏，不要因为等小程序审核而停下来。

照着做 · 打勾清单

1. 注册小程序账号（个人主体，新邮箱 + 身份证 + 微信扫码）
2. 想好 2–3 个备选名称，确定一个没被占用的
3. 拿到 AppID（开发管理 → 开发设置）
4. 下载安装微信开发者工具（稳定版 Windows 64）
5. 导入项目：目录选到「小程序版」这一层，后端服务选「不使用云服务」
6. 真机预览：五个页签都点一遍，勾选后退出重进验证数据留存
7. 上传代码，版本号 1.0.0
8. 配置用户隐私保护指引（设置 → 服务内容声明）
9. 提交审核：类目选「工具 → 效率」，测试账号留空，备注照抄
10. 审核通过后点「发布」
打勾状态会自动保存在本机，关掉页面再打开还在。
