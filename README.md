## 数据存储

所有打卡数据通过浏览器 `localStorage`（键名 `wb-checkin-v1`）保存在**你自己设备的浏览器里**。
这个仓库里只有一个静态 HTML 文件，不接收、也不存储任何打卡记录。

会丢失数据的情况：

- 换设备或换浏览器（数据不跟人走）
- 清理浏览器数据 / 使用无痕模式
- iOS Safari 连续 7 天未打开该页面（系统会自动清理本地存储）
- 更换访问网址（数据按网址隔离）

页面底部的 **「数据备份与恢复」** 可导出 JSON 备份，覆盖以上全部情况，也用于换设备时迁移。

## 更新流程

1. 修改 `index.html`
2. `git add -A && git commit -m "说明改了什么"`
3. `git push`
4. GitHub Pages 会自动重新发布，约 1 分钟后生效
